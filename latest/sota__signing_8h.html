Detailed Description

Ed25519 firmware-signature helpers for the SimpleOTA clients.

Portable (no platform dependencies) so it can be unit-tested on a host machine with plain cc/g++; see test/host/test_signing.c.

The SimpleOTA server delivers, for artifacts uploaded with security_mode "signed", a base64 Ed25519 signature computed over the raw firmware bytes exactly as downloaded. The device pins the project's PUBLIC key (it is not a secret) and must verify the signature over the downloaded bytes BEFORE the new image is marked bootable.

Verification is incremental (Monocypher's streaming Ed25519 check) so the image never has to fit in RAM: the apply path feeds the same chunks it writes to the OTA partition.

Macro Definition Documentation

◆ SOTA_VERIFIER_MAX_KEYS

#define SOTA_VERIFIER_MAX_KEYS   2

Streaming Ed25519 verifier over one firmware image, for up to two candidate public keys (key rotation windows).

Runs one Monocypher incremental check context per candidate key; the signature is accepted if it verifies under ANY candidate. Contexts are a few hundred bytes each (embedded SHA-512 state); the whole struct is about 700 bytes, so the apply path allocates it on the heap rather than on a task stack next to the download buffer.

Usage: sota_verifier_begin() once, sota_verifier_update() per downloaded chunk, sota_verifier_final() once.

Decide how to handle a (possibly signed) offer, from device policy and the offer's own claims.

Pure and host-testable.

The guard against stripped signatures lives here: a device that declares signed mode AND has a key pinned MUST see a usable signature, no matter what the offer claims. A compromised server or MITM that strips the security_mode / signature fields from the response therefore cannot silently downgrade the device to checksum-only flashing; it gets SOTA_GATE_FAIL_CLOSED. When the device is not enforcing (not in signed mode, or no key pinned), the offer's own declaration is trusted, which keeps basic-to-signed fleet migration flowing.

Parameters
device_reports_signedDevice is configured with security_mode "signed".
num_keysCount of pinned public keys (0..2).
offer_signedThe offer's security_mode is "signed".
offer_has_signatureA usable (decoded, ed25519) signature is present.

Parse a PEM "BEGIN PUBLIC KEY" (SubjectPublicKeyInfo) Ed25519 key, the exact format the SimpleOTA dashboard and API hand out.

The DER inside an Ed25519 SPKI is fixed-size (44 bytes: a constant 12-byte header followed by the 32 raw key bytes), so no ASN.1 parser is needed.

Parameters
pemNull-terminated PEM text (armor lines + base64 body).
outReceives the raw 32-byte public key on success.
Returns
true on success; false for malformed PEM, wrong key type, or wrong length. out is untouched on failure.
