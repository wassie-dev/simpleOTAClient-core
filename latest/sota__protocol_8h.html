Detailed Description

The SimpleOTA HTTP API's request bodies and the check response.

POST /api/v1/ota/check/ check-in; the response may offer an update POST /api/v1/ota/status/ one lifecycle event of a deployment

Request bodies are written into a caller's buffer, with every string value escaped, so a value from the server or the integrator can never break the JSON the server parses. Nothing here allocates.
