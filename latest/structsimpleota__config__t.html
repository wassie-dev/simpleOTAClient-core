Detailed Description

Configuration.

Zero-initialize, then set at least .token. All strings are copied at init; the struct and its strings need not outlive the call.

◆ is_connected

bool(* simpleota_config_t::is_connected) (void *user_ctx)

Return false while the link is down (e.g.

no IP yet). It is polled every second, and the check runs as soon as it returns true. NULL: always try. start() must then come after the IP arrives, or the first check fails and the next is check_interval_s later.

◆ event_cb

void(* simpleota_config_t::event_cb) (const simpleota_event_t *event, void *user_ctx)

Lifecycle events, called on the task that runs the update: the managed task, or the app's task in polling mode.

Keep it quick, and don't call the client from it except simpleota_reboot_for_update().

◆ cert_pem

const char* simpleota_config_t::cert_pem

TLS trust, always verified.

Default: the ESP-IDF certificate bundle, or on Arduino, which does not ship it, the ISRG Root X1 and X2 certificates that SimpleOTA's hosts chain to. Set cert_pem to pin a specific CA, or several concatenated, instead (then the bundle is not used).
