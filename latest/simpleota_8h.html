Detailed Description

The SimpleOTA client for ESP32, the same API in the ESP-IDF component and the Arduino library.

Thin client for the SimpleOTA firmware update platform (https://simpleota.com). Polls the check endpoint, streams and flashes offered firmware with on-the-fly SHA-256 and Ed25519 signature verification, reports lifecycle events, and runs every new image as a trial that rolls back unless it is confirmed.

The application owns network bring-up (Wi-Fi/Ethernet) and decides when the client may talk to the network via the optional is_connected callback; the client does the rest from its own background task (managed mode). In polling mode the application calls simpleota_check() and simpleota_apply() from its own task instead, and confirms a trial with simpleota_confirm(). Each runs on a short-lived task with CONFIG_SIMPLEOTA_TASK_STACK_SIZE while the caller waits, so the caller's stack size does not matter.

Quick start:

simpleota_config_t cfg = {0}; // {} in an Arduino sketch
cfg.token = "sota_pk_..."; // project (or device) token
cfg.is_connected = wifi_up; // or start after the IP arrives
ESP_ERROR_CHECK(simpleota_init(&cfg));
ESP_ERROR_CHECK(simpleota_start());

The device needs a partition table with two OTA app slots, which Arduino-ESP32's default has. On ESP-IDF, rollback by the bootloader needs CONFIG_BOOTLOADER_APP_ROLLBACK_ENABLE=y, which Arduino-ESP32 sets. Both ship with the first serial flash and cannot change over OTA. Without bootloader rollback the client rolls a failed trial back itself (CONFIG_SIMPLEOTA_SOFTWARE_ROLLBACK): on the confirm timeout, or on any reset before the confirm, as the bootloader would. It cannot catch an image that crashes before simpleota_init() on every boot.

The client is a process-wide singleton (one instance per device); a second simpleota_init() returns ESP_ERR_INVALID_STATE.

Thread-safety: configure and init from one task. After init the public functions are safe to call from any task, except that polling mode and simpleota_set_server_url() belong to one task of the application's.

Logs use the tag "simpleota". Warnings and errors show by default; esp_log_level_set("simpleota", ESP_LOG_DEBUG) after simpleota_init() shows every step.

Compatibility, which every later 1.x release keeps:

  • A configuration field left at zero (or NULL, or false) gets its default. New fields follow the same rule, so a config filled from {0} keeps building and keeps its behaviour.
  • Functions, fields, result values and event ids are only added, never changed or removed; check SIMPLEOTA_API_VERSION before using a newer one.
  • The reason tokens listed at simpleota_event_t are stable. New tokens may be added, so treat an unknown one as a generic failure.

esp_err_t simpleota_init ( const simpleota_config_t *  config)

Initialize the client: copy config, apply defaults, parse and pin signing keys, load persisted state, and run boot-time trial validation (detects rollbacks, arms the confirm timeout for trial boots).

Call it as early as possible, after nvs_flash_init() (Arduino-ESP32 has already called it): on a trial boot the confirm timeout starts here.

Parameters
configThe configuration; copied, so it need not outlive the call.
Return values
ESP_OKReady.
ESP_ERR_INVALID_ARGA missing token or one with control characters, an unparseable signing key, a security_mode out of range or SIGNED without a key, or a base_url that is not https://.
ESP_ERR_INVALID_STATEAlready initialized, or neither the certificate bundle nor a cert_pem is available.
ESP_ERR_NO_MEMOut of memory.

◆ simpleota_reboot_for_update()

esp_err_t simpleota_reboot_for_update ( void  )

Reboot into a downloaded update when disable_auto_reboot was set.

Until then the client does not download another update, because the next update slot holds the one waiting for this reboot.

Stops the background task, posts the "reboot" status from a short-lived task with CONFIG_SIMPLEOTA_TASK_STACK_SIZE (so any caller's stack is enough), and restarts.

Return values
ESP_ERR_INVALID_STATENo update is waiting. Otherwise it does not return.
