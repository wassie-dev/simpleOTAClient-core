Detailed Description

The key-value store the core persists its state in.

Implemented by the platform port (NVS namespace "simpleota" on ESP32) and by the host tests' fake. Bound at link time: the core calls these directly. Keys are at most 15 characters, the NVS limit.

Each set reaches storage on its own, before it returns: the core orders its writes so that a power cut between any two of them is recoverable.
