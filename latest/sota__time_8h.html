Detailed Description

Duration to FreeRTOS tick conversion.

pdMS_TO_TICKS() multiplies in 32 bits, so long durations wrap: past about 71 minutes at a 1000 Hz tick rate, or about 11.9 hours at 100 Hz. These helpers multiply in 64 bits and saturate instead. Every delay and timer period in both clients goes through them.

No platform types, so the host tests can include this header.
