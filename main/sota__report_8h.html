Detailed Description

Delivery and polling policy for deferred status reports.

"confirmed" and "rolled_back" are telemetry. What the server says about them never changes what the device does. A report is delivered once the server returns any HTTP response. Without a response it stays pending and is sent again on later checks: a few quick retries, then at the normal check interval.

No platform types, so the host tests can include this header.

Seconds until the next check.

connected: is_connected() allowed the check that just ran. While it does not, it is polled every SOTA_CONNECT_POLL_S, so the check runs as soon as the network is up instead of a whole check interval later. in_trial: a trial is running, so checks come every quick_s until it is confirmed or rolled back. report_pending: a confirmed or rolled_back report is waiting to be sent. report_failures: sends of that report that got no response this boot.
