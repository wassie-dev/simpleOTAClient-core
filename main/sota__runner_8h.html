Detailed Description

The managed task, implemented by the port (FreeRTOS on ESP32): it checks in on the engine's schedule, applies what is offered, and runs the confirm timeout's rollback.

Both clients' managed modes are this task, so they start, stop and supervise a trial the same way.

Ask the task to stop after its current step, so a download or flash write is never cut short, and wait up to timeout_ms for it.

From the task itself (a callback), returns true at once and the task stops after the callback. False when it is still running at the timeout.
