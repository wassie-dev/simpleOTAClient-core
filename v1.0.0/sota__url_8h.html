Detailed Description

The URLs the client may use: the server base URL for check-ins and status posts, and where a download redirect may lead.

Everything is https://; the offer's own download URL is checked on the apply path.

No platform types, so the host tests can include this header.

Where a download redirect from base leads, into out.

location is an absolute https:// URL, or a path starting with '/' on base's host. A redirect to plain HTTP is SOTA_URL_NOT_HTTPS; out is untouched unless the result is SOTA_URL_OK. out must not overlap base or location.
